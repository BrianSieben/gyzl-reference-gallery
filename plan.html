04b动手前要先拍板的 6 个问题

1业务四分法与网站分类如何对齐？

我们框架的作品分类是「全部 / AI / 影视 / 品牌广告」，而 PDF P4 的业务是「AI 影视 / IP 商业化 / IP 开发 / 商业广告」，两者不是一回事。

建议：双轨制 —— 作品列表按内容形态分（AI 广告 / 影视 / 品牌广告），首页 S7 服务能力按 PDF 业务线讲（品牌 AI 广告 / 影视 / IP 商业化 / IP 开发）。两套各自成立，互不冲突。

2预留的第四个分类放什么？

之前全站地图里第四个业务分类留空。PDF 给出了现成答案：自有 IP 三件套（DREAMLESS / 非相之界 / ZORA）。

建议：第四类定为「自有 IP」。这样四个 Tab = 全部 / AI 广告 / 影视 / 自有 IP，与 PDF 资产完全对齐；但"品牌广告"和"AI 广告"的边界需要先定义清楚（见问题 3）。

3"AI 广告"和"品牌广告"的边界？

PDF 里 13 个商业案例大多是"AI + 实拍"混合（美团世界杯、奥妙 TVC 有明显实拍成分），严格按"是否纯 AI"分会把案例切碎。

建议：AI 广告 = AIGC 占主导的片子（蛋的旅行、虚拟人 MV、TECNO、特斯拉概念片…）；品牌广告 = 实拍为主、AI 辅助的 TVC（奥妙、金典、木九十…）。 ambiguous 的默认进 AI 广告（毕竟品牌主张是 AI 公司）。

4签约导演 5 人墙放不放首页？

S10 团队入口需要导演肖像。PDF P9 有五个人名和履历，但肖像授权、是否愿意上官网都需要确认。

建议：确认授权后放首页 S10（这是差异信任状："别人讲技术，我们讲导演"）；不授权则改为名字墙 + 履历文字，不放照片。

5发展规划时间线（含保密项目）能上官网吗？

P25 有 2026Q2–2027Q1 四个节点，其中两个是保密项目。放在 S11 能制造期待感，但有泄露风险和时间跳票风险。

建议：上，但只写时间与一句话描述（如"2026Q4 · 优酷 S+ 级剧集，超级 IP 影视化"），不写出品方和 IP 名；已公开的（万花世界、乌尔善合作）正常写。

6案例详情页的「需求 + 过程稿」谁供给？

P4 三段叙事和过程稿条带是方案里最大的内容缺口，PDF 没有现成文字。

建议：客户提供每个案例的"一句话需求 + 三句过程描述"即可，我们负责扩写成统一版式；先做《万花世界》和《美团×李诞》两个样板给大家定调。
